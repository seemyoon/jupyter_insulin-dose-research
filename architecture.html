3. Multi-Task Loss

Loss = MSEmasked + bce_weight × BCEweighted
  • masked_mse — MSE only on drug slots where ground-truth dose > 0 REGRESSION
  • BCEWithLogitsLoss(pos_weight=...) — per-drug-type class weighting (neg/pos ratio, cap=15) CLASSIFICATION
  • bce_weight — fixed scalar (default 1.0) balancing the two tasks BALANCE

6. Training Pipeline Details

Data Preparation
  • Repository → raw ORM records (non-hospitalized patients)
  • MakeWindows → 24h sliding windows with CGM, CBG, ketone, food, doses
  • split_by_patient() → patient-level train 80% / val 10% / test 10%
  • MinMaxScaler fitted on training patients only (no leakage)
  • Measurement z-score normalization from training stats
  • Dose normalization: dose / max_dose_from_train
Hyperparameter Search
  • Optuna (Bayesian): hidden_size, num_rnn_layers, dropout, lr, batch_size, emb_dim
  • Grid Search: hidden_size, dropout, lr, batch_size
  • Early stopping with configurable patience
  • Reproducible via set_seed(42)
  • Pruning via MedianPruner
Classification Metrics (Drug Selection)
  • Precision — of predicted drugs, how many are correct?
  • Recall — of actual drugs, how many are found?
  • F1 — harmonic mean (main classification metric)
  • Exact Match — windows where all drug slots are correct
Regression Metrics (Dose Accuracy)
  • R² — coefficient of determination (1.0 = perfect, < 0 = worse than mean)
  • MAE — mean absolute error (normalized dose units)
  • Both computed only on active drug slots (where drug is prescribed)

7. Model Variants

GRU
  • GRU encoder for time-series
  • Fast training, fewer parameters
  • Good baseline for short sequences
LSTM
  • LSTM encoder (separate cell state)
  • Better long-range memory
  • Slightly more parameters than GRU
Hybrid XGBoost + LSTM
  • Stage 1: XGBoost learns dose baseline from static features
  • Stage 2: LSTM refines with temporal patterns
  • XGB predictions injected into fusion layer
